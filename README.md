# Farmer Plus

Build the FarmerPlus farm management app based on https://github.com/Steve-Monty/farmerplus: an installable farm management PWA with countryside home screen, translucent glass dock navigation, live weather widget, offline-ready local farm records with sync status badges, mini-apps directory (App Store with My Farm, My Animals, Farm Diary, Harvest, Field Mapping, Stock), Wallet, and Settings.

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://world-farm-whisperer.lovable.app
